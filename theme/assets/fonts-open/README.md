# Open fonts

Fallback faces under the SIL Open Font License, which allows shipping them here.

| File | Face | Used for |
| --- | --- | --- |
| `Geist-Regular.woff2` | Geist | text when Cassette is not installed |
| `GeistMono-Regular*.woff2` | Geist Mono | code and labels when Cassette Mono is not installed |
| `NotoSansJP-Regular.woff2` | Noto Sans JP | Japanese, which Cassette cannot set |
| `NotoSansKR-Regular.woff2` | Noto Sans KR | Korean, which Cassette cannot set |

Licence texts: `Geist-OFL.txt`, `NotoSans-OFL.txt`.
